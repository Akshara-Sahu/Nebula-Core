# Nebula-Core
An interactive code visualization playground with a VS Code-inspired editor and live previews.

Nebula Core lets you write and render diagrams and data visualizations in real time, all inside a single, familiar-feeling workspace. Whether you're sketching a flowchart, prototyping a D3 graph, or experimenting with a Three.js scene, Nebula Core gives you an editor on one side and an instant, interactive preview on the other.

✨ Features
Multi-library support — Create and edit visualizations across five major libraries in one place:
🧭 Mermaid — flowcharts, sequence diagrams, and more
📊 D3.js — custom, data-driven graphics
📈 Plotly — interactive charts and scientific plots
🎮 Three.js — 3D scenes and WebGL graphics
🕸️ Vis.js — network and graph visualizations
Flexible layouts — Switch between split-view, editor-only, and preview-only modes depending on your workflow.
VS Code-inspired editor — A familiar, keyboard-friendly coding experience built for speed and precision.
Extension management — Add, configure, and manage extensions to customize your workspace.
Live previews — See your changes rendered instantly as you type, no manual refresh required.
Responsive dark interface — A clean, modern UI designed for long coding sessions, on any screen size.

🚀 Getting Started
bash
# Clone the repository
git clone https://github.com/your-username/nebula-core.git
cd nebula-core

# Install dependencies
npm install

# Run the development server
npm run dev

Then open http://localhost:3000 in your browser to start creating.

📐 Usage
Select a visualization type (Mermaid, D3.js, Plotly, Three.js, or Vis.js) from the workspace.
Write or paste your code into the editor.
Watch the live preview update in real time.
Toggle between split-view, editor-only, or preview-only modes to fit your workflow.
Manage extensions to extend Nebula Core's capabilities as needed.
